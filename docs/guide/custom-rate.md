# 自定义汇率配置

支持为不同币种或不同操作员设置独立费率/汇率。

## 按币种配置

> 自定义关键词最多8字符，不能纯数字。设为0时默认同步当前群。

| 命令 | 说明 | 示例 |
|------|------|------|
| `设置欧元费率12` | 设置欧元费率 | 费率12% |
| `设置欧元汇率0.9` | 设置欧元汇率 | 汇率0.9 |
| `设置港币费率15` | 设置港币费率 | 费率15% |

配置后记账用法：

| 命令 | 说明 |
|------|------|
| `+10000/欧元` | 按欧元费率汇率记账 |
| `+10000/港币` | 按港币费率汇率记账 |

## 按人配置

| 命令 | 说明 |
|------|------|
| `设置张三费率5` | 给张三设费率5% |
| `设置张三汇率8` | 给张三设汇率8 |
| `设置李四费率6` | 给李四设费率6% |
| `设置李四汇率9` | 给李四设汇率9 |

记账用法：

| 命令 | 说明 |
|------|------|
| `张三+10000` | 按张三的费5汇8记账 |
| `李四+10000` | 按李四的费6汇9记账 |

## 删除配置

| 命令 | 说明 |
|------|------|
| `删除港币配置` | 删除港币配置 |
| `删除配置` | 清空所有自定义配置 |
