# 账单显示配置

在**个人中心**（私聊机器人点「👤 个人中心」）中配置。

## 可配置项

| 配置项 | 说明 |
|--------|------|
| 条数显示 | 账单显示最近多少条 |
| 显示时间 | 每条记录是否显示时间 |
| 分组功能 | 是否开启分组统计 |
| 全局日切 | 全局默认日切时间 |
| 关闭 xlsx | 关闭/开启导出 Excel |
| USDT 验证 | 开启后验证 USDT 地址 |
| 欢迎广告 | 入群欢迎语 |
| 账单币种 | 设置币种，默认 USDT |

## 命令行配置

| 命令 | 说明 | 示例 |
|------|------|------|
| `设置币种USDT` | 设置账单币种（仅字母） | 设置币种USDT |
