# 基本操作

所有命令在**群聊**中直接发送即可，无需斜杠前缀。

## 费率与汇率配置

| 命令 | 说明 | 示例 |
|------|------|------|
| `设置费率10` | 配置费率（支持负数%） | 设置费率10 → 费率10% |
| `设置汇率8` | 配置汇率 | 设置汇率8 → 汇率8 |
| `设置火币汇率` | 自动获取火币实时汇率 | 直接发送 |
| `设置欧易汇率` | 自动获取欧易实时汇率 | 直接发送 |
| `设置实时汇率` | 自动获取实时汇率 | 直接发送 |
| `配置汇率` | 实时汇率微调 | 直接发送 |
| `费率` 或 `配置` | 查看当前费率汇率配置 | 直接发送 |

## 操作员管理

| 命令 | 说明 | 示例 |
|------|------|------|
| `@用户名 添加操作员` | 增加记员 | @zhangsan 添加操作员 |
| `@用户名 删除操作员` | 移除记员 | @zhangsan 删除操作员 |
| `显示操作员` | 查看所有记员 | 直接发送 |
| `设置所有人操作员` | 把当前群员全设为操作员 | 直接发送 |
| `删除所有人操作员` | 移除所有操作员 | 直接发送 |

## 记账入账

| 命令 | 说明 | 示例 |
|------|------|------|
| `+10000` | 记账入账 | +10000 |
| `+10000/7.8` | 指定汇率入账 | +10000/7.8 |
| `+7777u` | U 后缀，自动按当前费率汇率计算 | +7777u |
| `+1000*12%` | 快捷按费率记账 | +1000*12% |
| `+1000 备注` | 带备注记账 | +1000 客户A |

## 代付减账

| 命令 | 说明 | 示例 |
|------|------|------|
| `-10000` | 代付减账 | -10000 |
| `-10000/7.8` | 指定汇率代付 | -10000/7.8 |
| `-7777u` | U 后缀代付 | -7777u |
| `-1000*105%` | 快捷费扣（免单笔手续费） | -1000*105% |

## 下发回分

| 命令 | 说明 | 示例 |
|------|------|------|
| `下发5000` | 下发回分 | 下发5000 |
| `下发-2000` | 下发修正（负数） | 下发-2000 |
| `下发1000R` | 人民币下发 | 下发1000R |
| `下发1000/7.8` | 指定汇率下发 | 下发1000/7.8 |

## 修正与撤销

| 命令 | 说明 | 示例 |
|------|------|------|
| `撤销` | 返回上一步 | 直接发送 |
| 回复消息 `撤销账单` | 删除指定账单 | 回复某条消息后发送 |
| `账单汇率8更新8.5` | 修正账单汇率 | 直接发送 |
| `账单入款汇率8更新8.5` | 修正入款汇率 | 直接发送 |
| `账单出款汇率8更新8.5` | 修正出款汇率 | 直接发送 |

## 清空账单

| 命令 | 说明 |
|------|------|
| `重置` 或 `清零` | 清空当前账单 |
| `删除账单` | 清空账单 |
| `结束账单` | 结束今日账单 |

## 账单查询

| 命令 | 说明 |
|------|------|
| `总账单` | 本月总账 |
| `上个月总账单` | 上月总账 |
| `我` 或 `账单` | 群员自查（回复自己的记录） |
| `张三 账单` | 查某人的账单 |
| `我的账单` | 操作员查自己的记录 |

## 账单寄存

| 命令 | 说明 |
|------|------|
| `/P+2000` | 寄存入账（统计在未下发） |
| `/P-1000` | 寄存出账 |

## 代付独立配置

> 代付必须用**减法**，单笔手续费额外扣每笔费用，代付费率用**负数**。

| 命令 | 说明 | 示例 |
|------|------|------|
| `设置手续费20` | 单笔手续费 | 每笔扣20元 |
| `设置代付费率-5` | 代付费率（负数） | -5% |
| `设置代付汇率8` | 代付汇率 | 汇率8 |
| `删除手续费` | 删除手续费配置 | 直接发送 |
| `删除代付费率` | 删除代付费率 | 直接发送 |
| `删除代付汇率` | 删除代付汇率 | 直接发送 |
