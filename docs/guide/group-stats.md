# 分组统计

按人名分组记账，支持分组查看明细。

## 分组记账

| 命令 | 说明 | 示例 |
|------|------|------|
| `张三+10000` | 分组入账 | 张三+10000 |
| `张三-10000` | 分组代付 | 张三-10000 |
| `张三 下发3000` | 分组下发 | 张三 下发3000 |
| `张三 下发-500` | 分组下发修正 | 张三 下发-500 |

## 分组按钮

记账后，账单消息下方会出现**分组按钮**，点击可展开/收起该分组明细。

| 命令 | 说明 |
|------|------|
| `开启分组缩展` | 开启分组折叠 |
| `关闭分组缩展` | 关闭分组折叠 |
