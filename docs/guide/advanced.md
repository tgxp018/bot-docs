# 附加操作

## 锁定操作

| 命令 | 说明 |
|------|------|
| 回复指定人消息 `加账` | 锁定给某人加账 |
| 回复指定人消息 `下发` | 锁定给某人下发 |
| 回复指定人消息 `账单` | 锁定查某人账单 |

## 日切设置

| 命令 | 说明 | 示例 |
|------|------|------|
| `设置日切04` | 设置每天4点自动清空 | 设置日切04 |
| `关闭日切` | 关闭日切（同步全局） | 直接发送 |
| `禁止日切` | 当前群独立不清空 | 直接发送 |

## 汇率查询

| 命令 | 说明 |
|------|------|
| `Z0` | 查询欧易实时汇率（OTC 支付宝报价） |
| `X0` | 欧易汇率 |
| `H0` | 火币汇率 |
| `全球汇率` | 各国汇率 |

## 币价计算

| 命令 | 说明 | 示例 |
|------|------|------|
| `币价7.25汇率10` | 计算费率% | 币价7.25汇率10 → 算费率 |
| `币价7.25费率25` | 转汇率 | 币价7.25费率25 → 算汇率 |

## 实用工具

| 命令 | 说明 | 示例 |
|------|------|------|
| 直接发送 T 开头地址 | 查 USDT 余额 | TJR...xxx |
| `查13800000***` | 查手机号归属 | 查13800001234 |
| `查4205041990****` | 查身份证信息 | 查420504199001011234 |
| `查621700220033****` | 查银行卡归属 | 查6217002200331234567 |
| `北京至上海` | 驾车距离 | 北京至上海（回复可改终点） |

## 群发广播

| 操作 | 说明 |
|------|------|
| 点底部「📢 群发广播」 | 进入群发菜单，选分组后发内容 |
| `/broadcast 分组名` | 命令行群发 |
| 回复消息 + `/broadcast 分组名` | 转发某条消息到该分组 |
| `创建广播分类 A` | 创建新分组 |
| `删除广播分类 A` | 删除分组 |

::: tip 群发支持
支持文字、图片、视频、文件、图文等媒体，自动限速 20 条/秒，失败自动记录。
:::

## 自定义按钮

> 仅最高权限人**私信机器人**配置，多个按钮换行，格式：`按钮名称|URL链接`

| 命令 | 说明 |
|------|------|
| 发送 `文字|跳转链接` | 添加自定义按钮 |
| `删除按钮` | 删除自定义按钮 |
